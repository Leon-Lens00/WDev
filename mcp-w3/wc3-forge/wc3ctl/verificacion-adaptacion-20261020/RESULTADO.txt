CAMBIOS NECESARIOS PARA UNA ADAPTACIÓN COMPLETA
ERROR — El proveedor base original usa CASC/Reforged. Portar formalmente el lector
MPQ probado, incluyendo GameDataContext y los comandos que aún abren CASC de forma
explícita (p. ej. snapshot y extracción de esquemas). Respetar prioridad de
War3Patch.mpq > War3xlocal.mpq > War3x.mpq > war3.mpq y nombres sin distinción de caja.

ERROR — `new` genera war3map.w3i versión 28 incluso con
WC3_TARGET_BUILD=TFT-v1.27b. Se comprobó extrayendo los bytes, no sólo leyendo código.
1.27b necesita versión 25 o anterior. Hacer que los mapas nuevos y sus guardados
respeten formatos Classic, JASS y límites 1.27b. El perfil de análisis existente no
convierte automáticamente los formatos ni garantiza todas las salidas de edición.

WARNING — Audio de Studio y MP3 usan APIs Windows (NAudio/Media Foundation,
WaveOut/WASAPI). Sustituirlas por audio Linux o deshabilitar explícitamente las
funciones no soportadas hasta implementarlas.

WARNING — Test in WC3, test-load y trazas lanzan ejecutables Windows directamente;
algunas funciones usan user32.dll/kernel32.dll. Integrar el lanzador Wine/Proton
existente y adaptar las sondas. El juego 1.27b seguirá ejecutándose mediante Wine.

WARNING — Setup de clientes, búsqueda de ejecutables, edición de PATH y asociaciones
incluyen supuestos Windows. Preparar lanzadores Linux y configuración MCP con rutas
Linux y objetivo explícito TFT-v1.27b. No usar install.ps1 como instalador CachyOS.

WARNING — Pruebas pendientes: edición/guardado de objetos y triggers con formatos
Classic, assets 1.27b, compilación JASS con la toolchain local y apertura de una copia
resultante en Warcraft III 1.27b. No se ejecutó toda la suite ni una prueba de juego.
