# Visor X3

Abrir index.html en navegador con WebGL o servir esta carpeta mediante `python -m http.server 8764 --bind 127.0.0.1`. Modelo/texturas están embebidos, sin servidor externo de assets. V2 a la izquierda, V3 a la derecha. Las referencias Vinz se conservan únicamente para estudio local con sus créditos originales en la biblioteca del proyecto. No distribuir ese conjunto como pack propio.

El botón Movimiento prueba sólo mueve la instancia en el visor, sin alterar MDX. Las emisiones se simulan con el renderer mdx-m3-viewer5.12.0; el aspecto exacto del motor Classic se verifica aparte. No usar los contadores de partículas como FPS. Librería y licencia adjuntas.
