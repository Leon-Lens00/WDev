<p>You may use any shell command as an API provider. This is particularly useful when you want to use a language or framework that is not directly supported by promptfoo.</p>
<p>While Script Providers are particularly useful for evaluating chains, they can generally be used to test your prompts if they are implemented in Python or some other language.</p>
<div class="theme-admonition theme-admonition-tip admonition_WCGJ alert alert--success"><div class="admonitionHeading_GCBg"><span class="admonitionIcon_L39b"><svg viewBox="0 0 12 16"><path fill-rule="evenodd" d="M6.5 0C3.48 0 1 2.19 1 5c0 .92.55 2.25 1 3 1.34 2.25 1.78 2.78 2 4v1h5v-1c.22-1.22.66-1.75 2-4 .45-.75 1-2.08 1-3 0-2.81-2.48-5-5.5-5zm3.64 7.48c-.25.44-.47.8-.67 1.11-.86 1.41-1.25 2.06-1.45 3.23-.02.05-.02.11-.02.17H5c0-.06 0-.13-.02-.17-.2-1.17-.59-1.83-1.45-3.23-.2-.31-.42-.67-.67-1.11C2.44 6.78 2 5.65 2 5c0-2.2 2.02-4 4.5-4 1.22 0 2.36.42 3.22 1.19C10.55 2.94 11 3.94 11 5c0 .66-.44 1.78-.86 2.48zM4 14h5c-.23 1.14-1.3 2-2.5 2s-2.27-.86-2.5-2z"></path></svg></span>tip</div><div class="admonitionContent_pbrs"><p><strong>Python users</strong>: there is a dedicated <a class="" href="/docs/providers/python/"><code>python</code> provider</a> that you may find easier to use.</p><p><strong>Javascript users</strong>: see how to implement <a class="" href="/docs/providers/custom-api/"><code>ApiProvider</code></a>.</p></div></div>
<p>To use a script provider, you need to create an executable that takes a prompt as its first argument and returns the result of the API call. The script should be able to be invoked from the command line.</p>
<div class="theme-admonition theme-admonition-note admonition_WCGJ alert alert--secondary"><div class="admonitionHeading_GCBg"><span class="admonitionIcon_L39b"><svg viewBox="0 0 14 16"><path fill-rule="evenodd" d="M6.3 5.69a.942.942 0 0 1-.28-.7c0-.28.09-.52.28-.7.19-.18.42-.28.7-.28.28 0 .52.09.7.28.18.19.28.42.28.7 0 .28-.09.52-.28.7a1 1 0 0 1-.7.3c-.28 0-.52-.11-.7-.3zM8 7.99c-.02-.25-.11-.48-.31-.69-.2-.19-.42-.3-.69-.31H6c-.27.02-.48.13-.69.31-.2.2-.3.44-.31.69h1v3c.02.27.11.5.31.69.2.2.42.31.69.31h1c.27 0 .48-.11.69-.31.2-.19.3-.42.31-.69H8V7.98v.01zM7 2.3c-3.14 0-5.7 2.54-5.7 5.68 0 3.14 2.56 5.7 5.7 5.7s5.7-2.55 5.7-5.7c0-3.15-2.56-5.69-5.7-5.69v.01zM7 .98c3.86 0 7 3.14 7 7s-3.14 7-7 7-7-3.12-7-7 3.14-7 7-7z"></path></svg></span>Structured provider responses</div><div class="admonitionContent_pbrs"><p>An <code>exec:</code> provider treats standard output as the response <code>output</code>, even when the script prints JSON. It cannot populate top-level fields such as <code>guardrails</code>. Use the <a class="" href="/docs/providers/python/#implementing-guardrails">Python</a>, <a class="" href="/docs/providers/ruby/#implementing-guardrails">Ruby</a>, <a class="" href="/docs/providers/custom-api/#guardrail-responses">JavaScript</a>, or <a class="" href="/docs/providers/http/#guardrails-support">HTTP</a> provider when an assertion needs a normalized guardrail response.</p></div></div>
<p>Your script receives three arguments:</p>
<ol>
<li class=""><strong>prompt</strong> - The rendered prompt string</li>
<li class=""><strong>options</strong> - JSON string with provider configuration</li>
<li class=""><strong>context</strong> - JSON string with test case variables, metadata, and evaluation info (see <a class="" href="/docs/providers/python/#the-context-parameter">Python provider context</a> for the full structure)</li>
</ol>
<p>Here is an example of how to use a script provider:</p>
<div class="language-yaml codeBlockContainer_mQmQ theme-code-block" style="--prism-color:#393A34;--prism-background-color:#f6f8fa"><div class="codeBlockContent_t_Hd"><pre tabindex="0" class="prism-code language-yaml codeBlock_RMoD thin-scrollbar" style="color:#393A34;background-color:#f6f8fa"><code class="codeBlockLines_AclH"><div class="token-line" style="color:#393A34"><span class="token key atrule" style="color:#00a4db">providers</span><span class="token punctuation" style="color:#393A34">:</span><span class="token plain"></span><br></div><div class="token-line" style="color:#393A34"><span class="token plain">  </span><span class="token punctuation" style="color:#393A34">-</span><span class="token plain"> </span><span class="token string" style="color:#e3116c">&#x27;exec: python chain.py&#x27;</span><br></div></code></pre></div></div>
<p>Or in the CLI:</p>
<div class="language-text codeBlockContainer_mQmQ theme-code-block" style="--prism-color:#393A34;--prism-background-color:#f6f8fa"><div class="codeBlockContent_t_Hd"><pre tabindex="0" class="prism-code language-text codeBlock_RMoD thin-scrollbar" style="color:#393A34;background-color:#f6f8fa"><code class="codeBlockLines_AclH"><div class="token-line" style="color:#393A34"><span class="token plain">promptfoo eval -p prompt1.txt prompt2.txt -o results.csv  -v vars.csv -r &#x27;exec: python chain.py&#x27;</span><br></div></code></pre></div></div>
