The intermediate destruction calls `TimerPool.unregister`, which decrements that count ([script.j:436](Systems/TimerTools/script.j#L436), [script.j:189–207](Systems/TimerTools/script.j#L189)).

- **Unregistered:** `destroy` only sets `disabled`; `CreationQueue.register` later destroys that pending node ([script.j:753](Systems/TimerTools/script.j#L753), [script.j:520](Systems/TimerTools/script.j#L520)).

`recycleTimer` pauses the native timer and pushes its ID onto the recycler ([script.j:280–283](Systems/TimerTools/script.j#L280)). This is static source evidence; runtime behavior was not tested.
