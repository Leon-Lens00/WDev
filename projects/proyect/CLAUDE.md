## Skills de Claude en este proyecto

Para cada skill nombrada por AGENTS.md, usar la adaptación del mismo nombre en
`.claude/skills/<nombre>/SKILL.md`. Las rutas `/home/snz/.codex/skills/` del
documento compartido identifican su equivalente Codex, no la interfaz de Claude.
En particular, Judgment Day usa la adaptación Claude con Agent/Explore y sólo se
lanza cuando el usuario lo solicita o acepta la propuesta; no usar spawn_agent.

Las fuentes activas están aquí y en el UI Studio indicado por AGENTS.md. WDev
contiene copias de respaldo; consultar el índice propietario de la revisión que
se modifica. Mantener separados los cambios de código de las copias para GitHub.
