## Historical library evidence

All bundled library profiles preserve inherited observations. Their sources, maps, compiler logs, installed toolchains and game sessions were **not independently reproduced in this correction**. No library source snapshots were supplied for this work. Labels such as Compiled, Validated and Tested in map inside profiles are historical claims only, unverified here; dates, hashes, API descriptions and defect findings identify the inherited record, not current certification. This applies also to InventorySys's dated inspection and to missile summaries.

For every profile, fields not explicitly established are **unknown**: license/copying permission, exact compiler fork/version/configuration, exact source snapshot/hash, dependency versions and complete lifecycle coverage. A listed historical author/version is not proof of a current download's identity. Described cleanup paths are not exhaustive lifecycle verification. A claimed absent dependency is specific to the historical variant, not all forks.

Before copying any implementation or assets:

1. Obtain the exact source snapshot, version/commit and SHA-256; match enabled variants and dependencies. Retain historical hashes unchanged as comparison evidence, not proof that an unavailable source matches.
2. Establish the license or explicit permission for the intended copying, modification and redistribution. A public URL or supplied map is not a grant. If unknown, stop copying; conceptual analysis may continue without redistributing source.
3. Record source/license evidence, actual compiler fork/version/options and patch-proven native inputs. Do not invent missing authors, dependencies or modern support.
4. Audit initialization, object rawcodes, single-owner infrastructure, callbacks and every ownership/termination path. Recompile the selected configuration and test its actual map artifact before promoting status.

Use the [library record](libraries-and-initialization.md) and [testing definitions](testing-matrices.md). External links in [sources](sources.md) are starting points, not a claim of current web verification. Only the alternate JassHelper manual and pJASS README were retrieved by the parent for this correction; neither authenticates an installed executable or certifies a library.
